## Project Context

Building an automated Dota 2 Steam Market scanner that:
- Runs on GitHub Actions cron (every 5 min)
- Fetches market listings for socketable items (couriers, wards, announcers, etc.)
- Parses listing HTML to detect Ethereal/Prismatic gems in sockets
- Compares prices against historical averages
- Sends Discord alerts for undervalued rare-socket items
- Stores data in Supabase PostgreSQL (free tier)
- Does NOT buy items — scan, analyze, notify only

---

## Global Constraints (from spec)

| Constraint | Value |
|------------|-------|
| **Scan cadence** | Every 5 minutes via GitHub Actions cron |
| **Rate limits** | 3s delay between requests; max 5 pages per item type |
| **Item types** | courier, ward, announcer, hud, loading_screen |
| **Retention** | 30 days (auto-cleanup job) |
| **Alert rules** | Hardcoded in `config.py` (3 rules: Ethereal < $100, Prismatic < $150, Any Rare Deep Discount 50%) |
| **Gem matching** | Curated JSON database + `rapidfuzz` fuzzy matching, confidence scoring |
| **Deduplication** | Hash alert content, 24hr cooldown per listing |
| **Database** | Supabase PostgreSQL, schema per spec |
| **Notifications** | Discord webhook, format per spec |
| **Python** | 3.11+, async with `httpx`, `beautifulsoup4`, `pydantic`, `asyncpg` |

#### Task 5: HTML parser for gem detection
**Files to create:**
- `src/steam/parser.py` — `ListingParser` class:
  - `parse_listing(html: str) -> ListingPageData` — extracts:
    - Item name (from `market_listing_item_name` or similar)
    - Price (from `market_listing_price` or similar)
    - Full description HTML
    - Gems: finds all socketed gems by parsing description for gem names (Ethereal/Prismatic patterns)

- `src/steam/__init__.py` — exports parser

**Test fixtures:** Save 3-5 real listing HTML samples to `tests/fixtures/listings/` for regression testing

**Acceptance:** Parses test fixtures correctly; extracts gem names matching known database

#### Task 6: Gem database & detector
**Files to create:**
- `data/gems.json` — curated list of known Ethereal & Prismatic gems with canonical names + aliases (from Dota 2 wiki / community sources)
- `src/analyzer/gem_detector.py` — `GemDetector` class:
  - Loads `gems.json` on init
  - `detect_gems(description_html: str) -> list[Gem]` — uses `rapidfuzz` to match gem names in description
  - Confidence scoring: exact=1.0, fuzzy≥0.85=0.8, partial≥0.7=0.5
  - Returns `Gem` objects with `gem_type` ('ethereal'/'prismatic'/'regular'), `gem_name`, `socket_index`, `is_rare`
- `src/analyzer/__init__.py` — exports detector

**Acceptance:** Detects gems in test fixtures with correct types; confidence scores match expectations

#### Task 8: Price analyzer
**Files to create:**
- `src/analyzer/price_analyzer.py` — `PriceAnalyzer` class:
  - `analyze_listing(listing: Listing, item: Item, gems: list[Gem]) -> list[AlertMatch]`
  - Computes: current price, 7-day average price, discount %
  - Matches against `ALERT_RULES` from config:
    - Rule 1: Ethereal gems, price < $100, discount ≥ 30%
    - Rule 2: Prismatic gems, price < $150, discount ≥ 25%
    - Rule 3: Any rare gem (ethereal/prismatic), price < $500, discount ≥ 50%
  - Returns `AlertMatch` with rule name, discount %, matched gem(s)
- `src/analyzer/__init__.py` — exports analyzer

**Acceptance:** Correctly calculates discounts; matches rules per spec; unit tests cover edge cases (no history, single listing, etc.)

### Phase 3: Main Logic & GitHub Actions (Tasks 10-12)

#### Task 10: Main scanner orchestration
**Files to create:**
- `src/main.py` — Entry point:
  - `async def scan_item_type(item_type: str)` — for each item type:
    - Search market (max 5 pages)
    - For each listing: fetch page HTML, parse, detect gems
    - Upsert item, insert listing + gems
    - Record price history
    - Analyze for alerts
    - Send alerts (deduplicated)
  - `async def main()` — runs scan for all `SCAN_CONFIG.item_types`
  - Logging: structured logs (listings checked, gems found, alerts sent, errors)
  - Graceful degradation: if listing page fails, still record price; retry gems on next scan
- `src/__init__.py` — exports main

**Acceptance:** Full scan runs end-to-end; logs show metrics; handles partial failures
